# OffboardCleaner · 离职数据安全清理工具（GUI 版）

用于离职/交接场景，**安全擦除**本机微信、QQ、企业微信的本地聊天记录，以及 Chrome / Edge 浏览器保存的密码与浏览记录（历史 / Cookie / 自动填充）。核心机制为**多次随机数据覆写 + 全零覆写后删除**，可阻止 Recuva、WinHex 等常规数据恢复工具还原内容。

> ⚠️ **操作不可逆**。执行前请确认已无需要保留的数据，并确认符合公司信息安全与离职交接政策。

## 二、界面与功能

启动后自动扫描本机应用数据，界面包含：

1. **环形扇形图**（左侧）：按应用展示数据占比（微信 / QQ / 企业微信 / Chrome / Edge 各色标识），**鼠标悬停扇形段放大**，中央实时显示对应应用的大小与占比；
2. **数据模块卡片**（右侧）：每个应用一张卡片（图标、数据大小、目标数），**鼠标悬停卡片放大上浮**，点击卡片可取消/恢复勾选；
3. **底部控制区**：覆写次数选择（3 次推荐 / 7 次更彻底）、「结束相关进程」（微信/QQ/企业微信/浏览器占用时使用）、「开始安全清理」；
4. **清理进度**：弹窗显示逐项进度条、当前覆写文件、百分比，支持取消；
5. 顶部徽章显示管理员状态，右上角可重新扫描。

## 三、使用方法

1. 先在各应用内退出登录（微信/QQ/企业微信 → 设置 → 退出登录），并关闭应用窗口；
2. 双击 **`OffboardCleaner.exe`**，等待自动扫描完成；
3. 核对扇形图与卡片清单，确认勾选无误；
4. 点「开始安全清理」→ 确认弹窗中输入确认 → 等待进度完成；
5. 若提示文件被占用，先点「结束相关进程」再重试。

> 提示：若磁盘为**机械硬盘（HDD）**，建议关闭应用后使用管理员 PowerShell 执行 `cipher /w:C` 覆写磁盘空闲空间，进一步清除文件残留。

## 四、清理范围

| 应用 | 清理内容 | 数据位置 |
|---|---|---|
| 微信 4.x | 聊天记录、图片视频、本地数据库 | `%APPDATA%\Tencent\xwechat`、`Documents\xwechat_files` |
| 微信（配置） | 登录配置、缓存 | `%APPDATA%\Tencent\WeChat` |
| 微信（旧版） | 旧版聊天记录 | `Documents\WeChat Files` |
| QQ | 配置、聊天记录 | `%APPDATA%\Tencent\QQ`、`Documents\Tencent Files` |
| 企业微信 | 聊天记录、接收文件、配置 | `Documents\WXWork`、`%APPDATA%\Tencent\WXWork` |
| Chrome / Edge | **保存的密码**（Login Data）、**Local State（密码加密密钥）**、浏览历史、Cookie、自动填充 | `%LOCALAPPDATA%\Google\Chrome\User Data`、`%LOCALAPPDATA%\Microsoft\Edge\User Data` |

> 浏览器采用**文件级**清理：只删密码/历史/Cookie/自动填充相关文件，**保留书签和扩展**。删除 `Local State` 后，即使 `Login Data` 被恢复，密码因加密密钥已销毁而**无法解密**。

## 五、擦除原理与"防恢复"边界

### 机制
每个文件执行 **N 次随机数据覆写 + 1 次全零覆写**（1MB 块写入、`os.fsync` 强制刷盘）后删除，再删除目录树；自动清除只读/隐藏属性；遇到符号链接只删除链接本身（防误删链接目标）。

### 边界
| 场景 | 说明 |
|---|---|
| 机械硬盘（HDD） | 覆写 3 次以上可有效阻止常规恢复；可配合 `cipher /w` 覆写空闲空间 |
| 固态硬盘（SSD） | 因磨损均衡（FTL），覆写不保证物理擦除。彻底方案：全盘 BitLocker 加密后销毁恢复密钥 / 厂商 Secure Erase |
| 云端 / 漫游 | 仅清本地。微信/QQ 云端记录需在应用内"退出登录/管理聊天记录"或注销时删除 |
| 系统还原（VSS） | 若开启系统还原，残留快照可在"磁盘清理 → 清理系统文件 → 更多选项 → 系统还原"中清除 |

## 六、安全设计

1. **白名单路径**：仅删除脚本内明确定义的目标，杜绝模糊删除；
2. **二次确认**：执行前弹窗列出全部目标，需明确确认；
3. **进程保护**：检测到应用运行时提示先结束进程（或一键结束）；
4. **符号链接防护**：重解析点只删链接本身，绝不递归进入链接目标；
5. **日志审计**：核心引擎操作可记录（脚本版输出日志文件）。
